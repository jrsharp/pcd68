# Welcome to JonSharp.net

This cyberterminal provides access to selected content from jonsharp.net in a classic text-based interface.

The system runs entirely on a virtual 68000 processor with hand-coded assembly language providing the user interface and content management.

## Navigation

Use the number keys (1-9) to select menu items.
- Press 'h' to return to the main menu from anywhere
- Press 'b' to go back to the previous screen
- Press 'q' to quit (when available)

## About This System

This is a demonstration of what's possible when combining:
- Classic 68000 assembly programming
- Modern emulation technology
- Gopher-inspired content presentation

Enjoy exploring!
