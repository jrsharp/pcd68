# Tools & Software

## Development Tools

### Cross-Platform Assemblers
- **VASM** - Multi-platform macro assembler supporting 68000
- **AS68K** - 68000 cross-assembler for various host platforms
- **GNU AS** - Part of GNU binutils, supports 68000 target

### Integrated Development Environments
- **EASy68K** - Windows-based 68000 development environment
- **Retro68** - Modern GCC-based toolchain for vintage Macs
- **SGDK** - Sega Genesis development kit with 68000 tools

### Emulators and Simulators
- **UAE** - Universal Amiga Emulator
- **Basilisk II** - 68k Macintosh emulator
- **Genesis Plus GX** - Sega Genesis/Mega Drive emulator
- **MAME** - Multiple Arcade Machine Emulator (supports many 68k systems)

## Hardware Tools

### PCB Design
- **KiCad** - Open source PCB design suite
- **Eagle** - Professional PCB design software
- **Altium Designer** - High-end PCB design platform
- **CircuitMaker** - Free community-driven PCB design tool

### Logic Analyzers
- **Saleae Logic** - USB logic analyzers for digital signal analysis
- **DSLogic** - Open source logic analyzer
- **PulseView** - Open source logic analyzer software

### Oscilloscopes
- **Rigol DS1054Z** - Popular entry-level digital oscilloscope
- **Siglent SDS1104X-E** - 4-channel digital oscilloscope
- **PicoScope** - PC-based oscilloscopes

## Vintage Computing Tools

### Disk Imaging
- **HxC Floppy Emulator** - Hardware floppy disk emulator
- **FluxEngine** - USB floppy disk interface for imaging
- **Kryoflux** - Professional floppy disk preservation system

### ROM Programming
- **TL866 Programmer** - Universal programmer for EPROMs and more
- **Willem Programmer** - Popular hobbyist EPROM programmer
- **Dataman Programmers** - Professional device programmers
