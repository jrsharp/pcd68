# Technical Projects

## PCD-68 Computer System

A virtual retro computer based on the Motorola 68000 processor. This system features:

**CPU Emulation**
- Complete MC68000 instruction set implementation
- Accurate timing and memory management
- Support for both user and supervisor modes

**Display System**
- Text Display Adapter (TDA) with 80x23 character display
- Support for 50-column and 80-column text modes
- Real-time character buffer management

**I/O Subsystem**  
- Keyboard Controller (KCTL) with USB HID support
- Dual UART implementation for serial communication
- Memory-mapped I/O with proper address decoding

**Development Environment**
- Complete assembly language toolchain
- ROM-based development with hot-reload capabilities
- Real-time debugging and trace facilities

**Apple II Enhancement Projects**
