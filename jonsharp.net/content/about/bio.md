# About Jon Sharp

Jon Sharp is a software engineer and hardware enthusiast with a passion for retro computing, embedded systems, and open source development.

He created the PCD-68, a virtual retro computer powered by a 68000 CPU emulator, as a platform for experimental software and hardware development.

Jon enjoys reviving old hardware, exploring retro computer architectures, and building electronic projects that blend vintage aesthetics with modern capabilities.
