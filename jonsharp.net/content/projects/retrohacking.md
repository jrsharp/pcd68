# Retrocomputing Projects

A collection of smaller retrocomputing projects that explore vintage computer systems and their capabilities.

## Canon Cat Restoration

Restoration and exploration of the Canon Cat, a unique text processor designed by Jef Raskin (original Macintosh creator). Projects include:
- Hardware repairs and maintenance
- Disk image recovery
- Documentation of undocumented features
- Development of new FORTH applications

## TRS-80 Model 100 Enhancements

Working with the portable TRS-80 Model 100:
- Custom memory expansion
- Modern storage solutions (SD card adapter)
- Terminal emulation improvements
- Custom software development

## Apple II Experiments

Various projects for the Apple II family:
- Graphics demos in assembly language
- Hardware interfacing with modern components
- Game development experiments
- Audio experimentation with the Mockingboard

## Collection and Preservation

Efforts to preserve vintage computing history:
- Documentation of rare systems
- Archiving software and manuals
- Restoration techniques
- Creating backups of fragile media
